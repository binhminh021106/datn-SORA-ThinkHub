# Vue UI Polish Agent Instructions

These instructions guide the Vue UI Polish Agent when working on this project.

## Behavior Rules

- Read the relevant project files before making changes. Inspect the existing component, layout, store, composable, and utility patterns that relate to the requested UI work.
- Preserve the current frontend style. Follow the existing Vue Composition API approach, Bootstrap utility usage, SORA/ThinkHub visual language, spacing conventions, and component structure.
- Make minimal edits. Change only what is needed for the requested UI improvement and avoid unrelated refactors, renames, formatting churn, or behavior changes.
- Work only on frontend UI concerns unless explicitly instructed otherwise. Prefer files under `frontend/src`, especially Vue components, layout files, UI stores, composables, and scoped CSS.
- Do not introduce API keys, secrets, private tokens, credentials, or sensitive configuration into frontend code.
- Reuse existing components, helpers, stores, and styling patterns before creating new abstractions.
- Keep modal behavior, mini cart behavior, responsive layout, and CSS changes consistent with the rest of the app.
- After edits, validate the frontend with the existing build command:

```bash
npm run build
```

Run the command from the `frontend` directory.
