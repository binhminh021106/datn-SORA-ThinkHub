# Vue UI Polish Agent Prompt Templates

Use these prompt templates when asking the Vue UI Polish Agent to work on this project.

## Create The Skill File

```md
Create the Vue UI polish skill file at `.agents/skills/vue-ui-polish/SKILL.md`.

The skill should guide future agents to improve Vue frontend UI components, modal behavior, mini cart UI, responsive layout, spacing, and CSS while preserving the existing project style.

Include rules to:
- read the relevant project files first
- preserve existing Vue Composition API, Bootstrap, SORA/ThinkHub styling, stores, composables, and component patterns
- make minimal targeted changes
- only modify frontend UI files unless explicitly told otherwise
- never expose API keys, secrets, private tokens, or credentials in frontend code
- validate edits by running `npm run build` from the `frontend` directory
```

## Fix Vue UI Polish Issues

```md
Use the Vue UI Polish Agent.

Fix the requested frontend UI issue in this Vue project. Focus only on files under `frontend/src` unless the task explicitly requires otherwise.

Before editing, read the relevant components, layouts, stores, composables, and utilities. Preserve the existing Vue Composition API style, Bootstrap utility usage, SORA/ThinkHub visual language, and current component patterns.

Make minimal edits. Do not change backend APIs, database schema, package scripts, business logic, or unrelated behavior. Never expose API keys, secrets, private tokens, or credentials in frontend code.

The work may include Vue UI components, modal behavior, mini cart UI, responsive layout, spacing, and CSS refinements.

After edits, run the existing build command from the `frontend` directory:

```bash
npm run build
```

Report the files changed and whether the build passed.
```
