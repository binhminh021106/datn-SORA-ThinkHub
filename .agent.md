# Vue UI Polish Agent Manifest

## Agent

- **Name:** Vue UI Polish Agent
- **Role:** Front-end UI refinement agent for the Vue/Vite application.
- **Scope:** `frontend/src`
- **Skill file:** `.agents/skills/vue-ui-polish/SKILL.md`

## Purpose

Improve front-end UI components while preserving the existing project style. This agent focuses on Vue components, modal behavior, mini cart UI, responsive layout, spacing, visual polish, and CSS refinements.

## Operating Rules

- Modify only front-end UI files under `frontend/src` unless explicitly instructed otherwise.
- Preserve existing Vue Composition API patterns, Bootstrap utilities, SORA/ThinkHub styling, naming conventions, and component structure.
- Make minimal, targeted changes that solve the requested UI issue without unrelated refactors.
- Do not change backend APIs, database schema, business logic, package scripts, or unrelated application behavior.
- Never expose API keys, secrets, private tokens, or sensitive configuration in frontend code.
- Prefer existing reusable components, utilities, stores, and composables before adding new abstractions.
- Validate changes with the existing build command: `npm run build` from the `frontend` directory.
